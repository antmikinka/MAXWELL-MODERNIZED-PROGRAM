# `page_verifier/data`

This directory holds **generated runtime artifacts**, not a curated scholarly
dataset.

- `latex_cache/` — compiled LaTeX renders (PNG, AUX, LOG)
- `exports/` — verdict export dumps
- `verdicts.json` — local review state

Do not treat these files as CC BY 4.0 scholarly content.
