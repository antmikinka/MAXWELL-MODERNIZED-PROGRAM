# Checklist: instrument-validation

## Purpose

Comprehensive validation checklist for instrument performance verification.

## Usage

Use this checklist when validating instrument performance. Rate each section 1-5 stars.

---

## Section 1: Theoretical Foundation

### Maxwell Article Coverage

- [ ] Relevant Maxwell articles referenced
- [ ] Operating principle correctly linked to Maxwell's theory
- [ ] Theory classification assigned

### Governing Equations

- [ ] Instrument equations correctly formulated
- [ ] CGS units used consistently
- [ ] Physical constants correctly specified

**Theoretical Foundation Rating:** ⭐⭐⭐⭐⭐ (1-5)

---

## Section 2: Static Characteristics

### Sensitivity

- [ ] Sensitivity calculated correctly
- [ ] Units consistent (CGS)
- [ ] Sensitivity within expected range

### Linearity

- [ ] Linearity measured over full range
- [ ] Maximum deviation documented
- [ ] Linearity within specification

### Accuracy

- [ ] Accuracy verified against standard
- [ ] Error within tolerance
- [ ] Hysteresis measured

### Resolution

- [ ] Resolution measured
- [ ] Resolution matches specification
- [ ] Resolution adequate for application

**Static Characteristics Rating:** ⭐⭐⭐⭐⭐ (1-5)

---

## Section 3: Dynamic Response

### Time Response

- [ ] Step response measured
- [ ] Rise time documented
- [ ] Settling time documented

### Frequency Response

- [ ] Bandwidth measured
- [ ] Frequency response flat within passband
- [ ] Resonance peaks identified

### Damping

- [ ] Damping ratio determined
- [ ] Response characteristic identified (under/critically/overdamped)
- [ ] Damping adjusted if required

**Dynamic Response Rating:** ⭐⭐⭐⭐⭐ (1-5)

---

## Section 4: Error Analysis

### Systematic Errors

- [ ] All systematic error sources identified
- [ ] Magnitude of each error quantified
- [ ] Corrections applied where possible

### Random Errors

- [ ] Repeatability measured
- [ ] Standard deviation calculated
- [ ] Distribution characterized

### Environmental Effects

- [ ] Temperature coefficient measured
- [ ] Humidity effects characterized
- [ ] EMI/RFI susceptibility tested

**Error Analysis Rating:** ⭐⭐⭐⭐⭐ (1-5)

---

## Section 5: Noise Performance

### Thermal Noise

- [ ] Thermal noise calculated
- [ ] Thermal noise measured
- [ ] Agreement between theory and measurement

### Other Noise Sources

- [ ] Shot noise characterized
- [ ] Flicker noise characterized
- [ ] Vibration noise characterized

### Signal-to-Noise Ratio

- [ ] SNR measured
- [ ] SNR adequate for application
- [ ] Minimum detectable signal determined

**Noise Performance Rating:** ⭐⭐⭐⭐⭐ (1-5)

---

## Section 6: Calibration

### Calibration Procedure

- [ ] Procedure documented
- [ ] Procedure followed
- [ ] Acceptance criteria met

### Standards Used

- [ ] Standards traceable
- [ ] Standards within calibration date
- [ ] Standards uncertainties documented

### Calibration Results

- [ ] Calibration data recorded
- [ ] Calibration curve fitted
- [ ] Residuals analyzed

**Calibration Rating:** ⭐⭐⭐⭐⭐ (1-5)

---

## Section 7: CGS Unit Consistency

### Unit Verification

- [ ] All measurements in CGS units
- [ ] Conversions documented
- [ ] No mixed unit systems

### Dimensional Analysis

- [ ] Equations dimensionally consistent
- [ ] Results have expected units
- [ ] Unit conversions verified

**Unit Consistency Rating:** ⭐⭐⭐⭐⭐ (1-5)

---

## Section 8: Documentation

### Technical Documentation

- [ ] Operating manual complete
- [ ] Calibration certificates filed
- [ ] Maintenance records current

### Performance Documentation

- [ ] Specification sheet complete
- [ ] Test reports filed
- [ ] Uncertainty analysis documented

**Documentation Rating:** ⭐⭐⭐⭐⭐ (1-5)
