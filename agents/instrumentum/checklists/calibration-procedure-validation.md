# Checklist: calibration-procedure-validation

## Purpose

Comprehensive validation checklist for calibration procedure verification.

## Usage

Use this checklist when validating calibration procedures. Rate each section 1-5 stars.

---

## Section 1: Procedure Documentation

### Procedure Completeness

- [ ] Scope clearly defined
- [ ] Equipment requirements listed
- [ ] Environmental conditions specified
- [ ] Step-by-step instructions provided
- [ ] Acceptance criteria defined

### Reference Documents

- [ ] Procedure number assigned
- [ ] Revision level current
- [ ] Related documents referenced
- [ ] Forms and templates included

**Procedure Documentation Rating:** ⭐⭐⭐⭐⭐ (1-5)

---

## Section 2: Standards and Equipment

### Standards Selection

- [ ] Standards appropriate for measurand
- [ ] Standards accuracy adequate (TUR ≥ 4:1)
- [ ] Standards traceable to national standards

### Standards Calibration

- [ ] All standards within calibration date
- [ ] Calibration certificates available
- [ ] Uncertainties documented

### Equipment Verification

- [ ] Equipment functionally verified
- [ ] Equipment specifications adequate
- [ ] Backup equipment available

**Standards and Equipment Rating:** ⭐⭐⭐⭐⭐ (1-5)

---

## Section 3: Environmental Conditions

### Condition Specifications

- [ ] Temperature range specified
- [ ] Humidity range specified
- [ ] Other conditions (pressure, vibration) specified

### Condition Monitoring

- [ ] Monitoring equipment available
- [ ] Conditions recorded during calibration
- [ ] Out-of-tolerance actions defined

### Condition Control

- [ ] Environment adequately controlled
- [ ] Stabilization time allowed
- [ ] Conditions within specification

**Environmental Conditions Rating:** ⭐⭐⭐⭐⭐ (1-5)

---

## Section 4: Calibration Steps

### Pre-Calibration

- [ ] Warm-up time specified
- [ ] Visual inspection performed
- [ ] Functionality verified
- [ ] Zero adjustment performed

### Calibration Execution

- [ ] Calibration points selected appropriately
- [ ] Increasing and decreasing values (hysteresis check)
- [ ] Multiple readings taken
- [ ] Data recorded completely

### Post-Calibration

- [ ] Adjustments made if necessary
- [ ] Verification after adjustment
- [ ] Labels/tags applied
- [ ] Documentation completed

**Calibration Steps Rating:** ⭐⭐⭐⭐⭐ (1-5)

---

## Section 5: Data Analysis

### Data Recording

- [ ] All required data fields completed
- [ ] Units consistent (CGS)
- [ ] Readings legible
- [ ] Corrections noted

### Statistical Analysis

- [ ] Mean values calculated
- [ ] Standard deviation calculated
- [ ] Outliers identified and handled
- [ ] Repeatability assessed

### Error Analysis

- [ ] Errors calculated (reading - standard)
- [ ] Percentages calculated correctly
- [ ] Tolerances applied correctly
- [ ] Pass/fail determination correct

**Data Analysis Rating:** ⭐⭐⭐⭐⭐ (1-5)

---

## Section 6: Uncertainty Evaluation

### Uncertainty Sources

- [ ] All sources identified
- [ ] Type A uncertainties evaluated
- [ ] Type B uncertainties evaluated

### Uncertainty Calculation

- [ ] Sensitivity coefficients determined
- [ ] Combined uncertainty calculated
- [ ] Expanded uncertainty calculated
- [ ] Coverage factor appropriate

### Uncertainty Reporting

- [ ] Uncertainty statement complete
- [ ] Confidence level stated
- [ ] TUR calculated and acceptable

**Uncertainty Evaluation Rating:** ⭐⭐⭐⭐⭐ (1-5)

---

## Section 7: Traceability

### Traceability Chain

- [ ] Unbroken chain to national standards
- [ ] All links documented
- [ ] Certificates available

### Traceability Documentation

- [ ] Traceability statement included
- [ ] Certificate numbers recorded
- [ ] Calibration dates recorded

**Traceability Rating:** ⭐⭐⭐⭐⭐ (1-5)

---

## Section 8: CGS Unit Consistency

### Unit Usage

- [ ] All values in CGS units
- [ ] Conversions documented
- [ ] No mixed unit systems

### Unit Verification

- [ ] Dimensional analysis verified
- [ ] Conversion factors correct
- [ ] Results have expected units

**Unit Consistency Rating:** ⭐⭐⭐⭐⭐ (1-5)
