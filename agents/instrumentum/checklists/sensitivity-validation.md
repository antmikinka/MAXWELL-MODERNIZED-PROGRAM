# Checklist: sensitivity-validation

## Purpose

Comprehensive validation checklist for instrument sensitivity verification.

## Usage

Use this checklist when validating instrument sensitivity. Rate each section 1-5 stars.

---

## Section 1: Theoretical Sensitivity

### Formula Verification

- [ ] Sensitivity formula correctly derived
- [ ] All parameters identified
- [ ] Formula consistent with Maxwell's theory

### Parameter Values

- [ ] All parameters measured/verified
- [ ] Parameters within expected ranges
- [ ] CGS units used consistently

### Calculated Sensitivity

- [ ] Sensitivity calculated correctly
- [ ] Result has correct units
- [ ] Result physically reasonable

**Theoretical Sensitivity Rating:** ⭐⭐⭐⭐⭐ (1-5)

---

## Section 2: Measured Sensitivity

### Measurement Setup

- [ ] Setup correctly configured
- [ ] Input standards traceable
- [ ] Environmental conditions controlled

### Measurement Procedure

- [ ] Procedure documented
- [ ] Multiple measurements taken
- [ ] Data recorded completely

### Measurement Results

- [ ] Sensitivity measured over full range
- [ ] Linearity verified
- [ ] Results consistent with theory

**Measured Sensitivity Rating:** ⭐⭐⭐⭐⭐ (1-5)

---

## Section 3: Noise-Limited Sensitivity

### Noise Sources Identified

- [ ] Thermal noise considered
- [ ] Shot noise considered
- [ ] Flicker noise considered
- [ ] Vibration noise considered

### Noise Measurements

- [ ] Noise spectrum measured
- [ ] Noise bandwidth defined
- [ ] RMS noise calculated

### Minimum Detectable Signal

- [ ] MDS calculated from noise
- [ ] MDS verified experimentally
- [ ] MDS adequate for application

**Noise-Limited Sensitivity Rating:** ⭐⭐⭐⭐⭐ (1-5)

---

## Section 4: Dynamic Sensitivity

### Frequency Response

- [ ] Sensitivity measured vs. frequency
- [ ] Bandwidth determined
- [ ] Corner frequencies identified

### Phase Response

- [ ] Phase shift measured
- [ ] Phase linearity verified
- [ ] Group delay characterized

### Time Domain Response

- [ ] Step response measured
- [ ] Rise time determined
- [ ] Settling time determined

**Dynamic Sensitivity Rating:** ⭐⭐⭐⭐⭐ (1-5)

---

## Section 5: Environmental Effects

### Temperature Dependence

- [ ] Temperature coefficient measured
- [ ] Operating temperature range verified
- [ ] Temperature compensation evaluated

### Humidity Effects

- [ ] Humidity coefficient measured
- [ ] Humidity range verified

### Other Environmental Factors

- [ ] Pressure effects (if applicable)
- [ ] Vibration effects characterized
- [ ] EMI/RFI susceptibility tested

**Environmental Effects Rating:** ⭐⭐⭐⭐⭐ (1-5)

---

## Section 6: Stability and Drift

### Short-Term Stability

- [ ] Short-term drift measured
- [ ] Noise floor stable
- [ ] Zero point stable

### Long-Term Stability

- [ ] Long-term drift measured
- [ ] Aging effects characterized
- [ ] Recalibration interval determined

### Warm-Up Effects

- [ ] Warm-up time determined
- [ ] Warm-up drift characterized
- [ ] Warm-up procedure documented

**Stability Rating:** ⭐⭐⭐⭐⭐ (1-5)

---

## Section 7: CGS Unit Consistency

### Unit Verification

- [ ] All values in CGS units
- [ ] Conversions documented
- [ ] Dimensional analysis verified

### Unit Conversions

- [ ] Conversion factors correct
- [ ] Conversions verified
- [ ] No mixed unit systems

**Unit Consistency Rating:** ⭐⭐⭐⭐⭐ (1-5)

---

## Section 8: Comparison and Optimization

### Theory vs. Measurement

- [ ] Theory and measurement agree
- [ ] Discrepancies explained
- [ ] Corrections applied

### Optimization

- [ ] Sensitivity optimized
- [ ] Trade-offs documented
- [ ] Recommendations provided

**Comparison/Optimization Rating:** ⭐⭐⭐⭐⭐ (1-5)
