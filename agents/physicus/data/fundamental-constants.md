## Derived Constants

### Electromagnetic Relations

```
Fine structure: α = e²/(ℏc) = 1/137.036
Bohr magneton: μ_B = eℏ/(2m_e c) = 9.274×10⁻²¹ erg/gauss
Bohr radius: a₀ = ℏ²/(m_e e²) = 5.292×10⁻⁹ cm
Rydberg: Ry = m_e e⁴/(2ℏ²) = 2.180×10⁻¹¹ erg
```

### Thermal Relations

```
Thermal voltage: V_T = k_B T / e
  At T = 293K: V_T = 0.0253 statvolt = 7.58 volt
Thermal energy: k_B T
  At T = 293K: k_B T = 4.046×10⁻¹⁴ erg
```
