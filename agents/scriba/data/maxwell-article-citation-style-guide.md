# Data: maxwell-article-citation-style-guide

## Purpose

Standardized citation style guide for referencing Maxwell's Treatise on Electricity and Magnetism.

---

## Full Citation Format

### Book Citation

```
Maxwell, J.C. (1873). A Treatise on Electricity and Magnetism (3rd ed.). 
Clarendon Press, Oxford.
```

### Article Citation

```
Maxwell, J.C. (1873). A Treatise on Electricity and Magnetism. 
Part [Roman Numeral], Chapter [Roman Numeral], Art. [Article Range]: [Topic].
```

### Example

```
Maxwell, J.C. (1873). A Treatise on Electricity and Magnetism (3rd ed.). 
Clarendon Press, Oxford. Part IV, Chapter XVII, Art. 730-750: Galvanometry.
```

---

## In-Text Citation Formats

### Parenthetical Citation

```
(Maxwell, 1873, Art. 730-750)
(Maxwell, 1873, Part IV, Art. 730-750)
```

### Narrative Citation

```
Maxwell (1873, Art. 730-750) states that...
According to Maxwell (1873, Part IV, Art. 730-750)...
```

### Short Form (after first full citation)

```
(Maxwell, Art. 730-750)
Maxwell, Art. 730-750
```

## Article Range Format

### Single Article

```
Art. 730
```

### Article Range (consecutive)

```
Art. 730-750
```

### Multiple Articles (non-consecutive)

```
Art. 730, 735, 742
```

### Multiple Ranges

```
Art. 730-750, 751-770
```

## CGS Unit Citation

### When Discussing Units

```
All electrical quantities are expressed in CGS units throughout 
Maxwell's Treatise (Art. 1-50), following Maxwell's convention:

- Potential: statvolt (statV)
- Current: statampere (statA)
- Resistance: statohm (statΩ)
- Charge: statcoulomb (statC)
- Capacitance: statfarad (statF)
```

### Physical Constants

```
Physical constants in CGS units:

- Boltzmann constant: k_B = 1.381×10^-16 erg/K
- Elementary charge: q = 4.803×10^-10 statC
- Speed of light: c = 2.998×10^10 cm/s
```

## Quotation Format

### Short Quotation (inline)

```
Maxwell (1873, Art. 730) defines the galvanometer as "an instrument 
for measuring electric currents."
```

### Long Quotation (block)

```
Maxwell (1873, Art. 730-750) states:

    "The galvanometer is an instrument for measuring electric 
    currents. Its construction depends on the principle that a 
    current-carrying conductor experiences a force when placed 
    in a magnetic field."
```

## Common Mistakes to Avoid

### Incorrect

```
(Maxwell, 1873, p. 730)  [Wrong: uses page numbers]
(Maxwell, Art. 730-750)  [Missing year in first citation]
Maxwell (Art. 730-750)   [Missing year]
```

### Correct

```
(Maxwell, 1873, Art. 730-750)
Maxwell (1873, Art. 730-750)
(Maxwell, Art. 730-750) [after first full citation]
```
