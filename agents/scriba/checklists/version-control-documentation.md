## Version Numbering Guide

### Semantic Versioning

```
MAJOR.MINOR.PATCH

MAJOR: Incompatible changes
MINOR: Backward-compatible features
PATCH: Backward-compatible bug fixes
```

### Pre-release Versions

```
1.0.0-alpha
1.0.0-beta
1.0.0-rc.1
```

### Build Metadata

```
1.0.0+build.123
```
