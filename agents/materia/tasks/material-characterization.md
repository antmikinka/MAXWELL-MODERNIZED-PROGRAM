# Task: material-characterization

## Description

Characterize material electromagnetic properties through measurement and simulation.

## Workflow Steps

1. Prepare material sample
2. Measure properties
3. Fit models to data
4. Validate characterization

## Requirements

**Input:**
- `material`: Material sample
- `property_type`: electromagnetic property
- `measurement_method`: characterization technique

**Output:**
- `properties`: dict - Material properties
- `uncertainty`: dict - Measurement uncertainty
- `model_fit`: Model parameters
